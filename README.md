# Data-Analysis-using-Power-BI-and-Tableau

A hands-on portfolio project exploring interactive business intelligence dashboards built with **Microsoft Power BI** and **Tableau**. The project demonstrates sales, product, category, geographic, monthly, and revenue analysis using both visualization tools.

## Project Overview

This repository contains:

- Power BI reports and dashboards
- A Tableau workbook
- Excel and XLS data sources
- Dashboard screenshots for quick review

The dashboards turn raw sales records into clear visual insights about revenue, product performance, regional trends, categories, and time-based patterns.

## Key Analysis Areas

- Sales and revenue performance
- Units sold and average selling price
- Monthly and yearly sales trends
- Category and sub-category comparison
- Product and beverage-brand analysis
- Geographic and state-level sales
- Order and shipment patterns
- Profit and discount analysis

## Tableau Workbook

The Tableau workbook uses the **Sample - Superstore** dataset and includes the following views:

- **Category wise Sales** - compares sales across categories and sub-categories
- **Monthly sales over years** - shows sales patterns over time
- **Sales Visualization over Map** - displays geographic sales distribution

Open `Data Analysis using Tableau.twb` in Tableau Desktop and keep `Sample - Superstore.xls` in the repository so Tableau can resolve the workbook's data source.

## Power BI Reports

The repository includes two `.pbix` report files:

- `Sales Performance Dashboard.pbix` presents revenue, units sold, average price per unit, beverage brands, monthly revenue, and state-level sales.
- `Data Analysis using Power BI.pbix` contains the broader Power BI analysis created from the included practice datasets.

Open these files with Microsoft Power BI Desktop. If Power BI prompts for a data source location, update the source paths in **Transform data > Data source settings**.

## Getting Started

### Prerequisites

- [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/) for `.pbix` files
- [Tableau Desktop](https://www.tableau.com/products/desktop) or Tableau Public for the `.twb` workbook
- Microsoft Excel or a compatible spreadsheet application for the `.xlsx` and `.xls` files

### How to Use

1. Clone or download this repository.
2. Open the Tableau workbook or a Power BI report.
3. Verify that the report is connected to the appropriate data source.
4. Explore filters and chart tooltips.
5. Review the matching PNG image for a static dashboard preview.

```bash
git clone https://github.com/salehapopy66/Data-Analysis-using-Power-BI-and-Tableau.git
cd Data-Analysis-using-Power-BI-and-Tableau
```
